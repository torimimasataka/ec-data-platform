## 各コンポーネント詳細

### ヘッダー

| 要素 | 設定 |
|---|---|
| タイトルテキスト | `EC Sales Dashboard — Summary` |
| 期間フィルター | `order_month`（DATE型）でフィルター。デフォルト: 直近12ヶ月 |
| フォントサイズ | タイトル 24px、サブテキスト 12px グレー |

---

### KPIカード（6枚横並び）

#### KPI① 月次売上合計

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `sum_price_month`（SUM） |
| 比較対象 | 前期間比（期間フィルターと連動） |
| 表示形式 | ¥ + カンマ区切り（例: ¥1,234,567） |
| 増減表示 | ↑ 緑 / ↓ 赤 |

#### KPI② 月次注文数

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `cnt_orders_month`（SUM） |
| 比較対象 | 前期間比 |
| 表示形式 | カンマ区切り整数（例: 1,234） |

#### KPI③ 平均注文単価（AOV）

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `aov_month`（AVG） |
| 比較対象 | 前期間比 |
| 表示形式 | ¥ + 小数第1位（例: ¥154.2） |

#### KPI④ 月次ユニーク顧客数

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `cnt_active_customers_month`（SUM） |
| 比較対象 | 前期間比 |
| 表示形式 | カンマ区切り整数 |

#### KPI⑤ リピーター率

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `repeat_customer_rate_month`（AVG） |
| 比較対象 | 前期間比 |
| 表示形式 | % 小数第1位（例: 3.1%） |

#### KPI⑥ 年累計売上（YTD）

| 項目 | 設定 |
|---|---|
| チャート種類 | スコアカード |
| 指標 | `sum_revenue_ytd`（MAX — 期間内の最新月の累計値を使用） |
| 比較対象 | 前年同期比 |
| 表示形式 | ¥ + カンマ区切り（例: ¥8,234,567） |
| 備考 | 期間フィルターで選択した最終月時点のYTD値を表示 |

---

### 月次売上トレンド（複合グラフ）

| 項目 | 設定 |
|---|---|
| チャート種類 | 複合グラフ（棒 + 折れ線） |
| ディメンション | `order_month`（X軸） |
| 指標①（棒） | `sum_price_month`（売上）色: `#1A73E8` |
| 指標②（折れ線） | `cnt_orders_month`（注文数）色: `#34A853`、右Y軸 |
| 指標③（折れ線） | `avg_review_score_month`（平均レビュースコア）色: `#FBBC04`（Yellow）、右Y軸（0〜5スケール） |
| X軸フォーマット | `MMM yyyy`（例: Jan 2018） |
| データポイント | 全月表示（23ヶ月） |
| フィルター連動 | 期間フィルターと連動 |
| 備考 | YTD表示はKPIカードで対応するためここでは月次のみ |

---

### カテゴリ別売上 Top10（横棒グラフ）

| 項目 | 設定 |
|---|---|
| チャート種類 | 横棒グラフ |
| データソース | `app_category_performance` |
| ディメンション | `product_category_name_english` |
| 指標 | `sum_price_all_time`（全期間売上合計） |
| 並び順 | 売上降順 |
| 表示件数 | 上位10件 |
| 色 | `#1A73E8` 単色 |
| 期間フィルター連動 | あり（`order_month` で連動） |
| 指標切替 | `sum_price_month`（期間内売上合計）で集計 |

---

### 州別注文数ジオマップ

| 項目 | 設定 |
|---|---|
| チャート種類 | ジオマップ（地図） |
| データソース | `app_geo_summary` |
| 場所ディメンション | `state_code_iso`（`BR-SP` 形式） |
| 指標 | `cnt_orders_month`（SUM） |
| 地域設定 | ブラジル（Brazil） |
| カラースケール | 薄青 → 濃青（注文数に応じたグラデーション） |
| 期間フィルター連動 | あり |
